# CodeQuest - Pensamento Computacional

Versão atualizada com uma fase prática inicial sobre os 4 pilares do pensamento computacional.

## Fluxo do site

1. Introdução ao pensamento computacional.
2. Jogo dos 4 pilares:
   - Decomposição
   - Padrões
   - Abstração
   - Algoritmos
3. Teoria sobre algoritmos.
4. Prática: tabuleiro com comandos de setas.
5. Teoria sobre fluxogramas.
6. Prática: organização de blocos lógicos.
7. Teoria sobre introdução à programação.
8. Prática: desafios básicos em JavaScript.
9. Certificado final com XP total.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` no navegador.
